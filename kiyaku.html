ご依頼の前にお読みくださいご利用規約

本規約では、当方がお引き受けすること、ご本人にお願いすること、お預かりしたものの取り扱いについて、あらかじめ定めます。申込書にご署名いただいた時点で、本規約に同意したものとみなします。

第1条　お渡しするもの

  1. 申込書に記載したもの一式を、申込書に記載した期日までにお渡しします。お渡しする形式は PDF です。綴・見立帖は、まとめの頁を A4 用紙に印刷して郵送でもお届けします。印刷製本版をご希望の場合は、申込書にその旨をご記入ください。郵送でお届けします。
  2. 当方は、調べた資料の名称を一つずつ挙げ、そこから言えることに確かさの度合いを付けてお渡しします。どこまで見つかるかは資料しだいですので、結果そのものはお約束できません。
  3. 調べた記録のうち、お名前が載っていなかった記録についても、その記録名を挙げてお渡しします。それも調べの結果のひとつです。
  4. 読み取った字と、資料から言えることには、確かさの度合いを添えます。迷いのある字は、迷いのあるまま記します。
  5. 系図は観賞と記念のためのものです。相続その他の手続きに用いる書類とは別のものです。

第2条　ご本人にお願いすること

ご本人にしかできないことが、いくつかあります。

  1. 戸籍（除籍謄本など）の請求と署名。請求できるのは、ご本人、配偶者、直系尊属、直系卑属に限られます。請求書を作成できるのは、ご本人または行政書士です。当方は、どの役場に、誰の、どの範囲の戸籍を請求するかをご案内し、書き方の見本をお渡しします。
  2. お寺・ご親戚・役場へのお声がけ。先方とのご縁はご本人のものです。当方は文案をお作りします。
  3. 現地での撮影。
  4. 家紋と菩提寺のご確認（印刷前に一度確認いたします）。

第3条　お預かりするもの

  1. 原本は、撮影が済みしだい、書留でお返しします。お預かりしている期間と内容は、「預かり証」に記載します。返却時には、原本を綴じて箱に入れてお返しします。
  2. 撮影した画像は当方が管理する保管場所に保存し、当方のみが閲覧します。お渡しから1年後に削除します（削除する日を申込書に記します）。
  3. 解読には、米国の事業者が提供する外部の AI サービスを使います。入力した情報は、学習に使用しない設定にしています。
  4. 台帳と完成したデータは、暗号化した状態でお渡しします。当方が仕事をやめても、家の記録はお手元に残ります。
  5. ご存命の方のことは、公開するものには載せません。
  6. お名前・ご住所は、この仕事のためだけに使います。取り扱いは「個人情報の取り扱い（プライバシーポリシー）」のとおりです。

第4条　お支払いとお取消し

  1. 料金は申込書に記載した額です。綴・一葉、綴・見立帖、綴・伝承帖の料金は、お申込みのときに確定します。「戸籍で家系図をつくる」の料金は、除籍謄本の綴りが揃った時点で確定します。7綴り目以降は、1綴りにつき5,000円を加算します。
  2. 成功報酬にはいたしません。見つかった量が見込みより多くても少なくても、額は申込書のとおりです。
  3. お代は着手の前に全額いただきます。着手より前のお取消しは、いただいたものを全額お返しします。着手後に取り消される場合は、その時点までに完了した成果物をお渡しし、未実施分の料金をお返しします。
  4. 原本をお預かりしたあとでお取消しになるときも、原本は書留でお返しします（送料は当方が負担します）。

第5条　書いたものの扱い

  1. 画像は、パブリックドメインのもの、または所蔵機関の許可を得たものに限って掲載し、出典を明記します。翻刻を引用する場合も、出典を明記します。
  2. 伝承帖に入れる絵は、生成AIによって作成した画像（生成画像）です。伝承帖の冒頭に、生成画像を使用していることを明記します。どこまでが記録にあることかを注に記します。
  3. いただいた系図や言い伝えは、出典が確認できたものに限り、公開する冊子に記載します。
  4. できあがったものをご家族やご親戚にお配りになるのは、ご自由です。

第6条　お調べする範囲

お調べするのは、家の来歴です。出自の詮索や、差別につながる調査はお受けしません。
